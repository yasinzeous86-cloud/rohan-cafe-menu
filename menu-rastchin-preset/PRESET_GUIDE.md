# راهنمای جامع پکیج پایه و قالب‌سازی راست‌چین (Rastchin Preset & Theme Boilerplate)

این پکیج، هسته‌ی مهندسی‌شده و استاندارد منوی آنلاین، مدیریت سفارشات، کیوآر اختصاصی میز و ربات تلگرام را به صورت **کاملاً ماژولار و مستقل از ظاهر کافه رُهان** در اختیار شما قرار می‌دهد. توسعه‌دهندگان فرانت‌اند و طراحان وب می‌توانند هر نوع قالب دلخواه HTML/CSS/Tailwind را بدون نیاز به دستکاری کدهای PHP یا ساختار دیتابیس، بر روی این هسته سوار کنند.

---

## 📁 ساختار فایل‌های پکیج پایه (`menu-rastchin-preset/`)

```text
menu-rastchin-preset/
├── api.php                # موتور اصلی REST API (احراز هویت، محصولات، سفارشات، کیوآر، آمار)
├── webhook.php            # پردازشگر وب‌هوک و دستورات ربات تلگرام (آنالیز پرفروش‌ها، استعلام و ثبت)
├── admin.html             # پنل مدیریت تک‌صفحه‌ای اختصاصی (CRUD، پریست‌ها، بارکد میزها، تنظیمات)
├── index.html             # قالب مرجع فرانت‌اند مشتری بر پایه قلاب‌های data-attribute
├── menu.sqlite            # دیتابیس سبک و بدون نیاز به نصب SQLite (آماده و پاک‌سازی شده)
├── sw.js                  # سرویس‌ورکر PWA جهت اجرای ۱۰۰٪ آفلاین منو
├── manifest.json          # پیکربندی وب‌اپلیکیشن قابل نصب در موبایل
├── PRESET_GUIDE.md        # همین راهنما
└── assets/
    ├── app.js             # موتور اتصال فرانت‌اند به دیتابیس با استاندارد Contract Hooks
    ├── style.min.css      # استایل‌های بهینه‌سازی شده و فونت‌ها
    ├── qr.min.js          # کتابخانه جاوااسکریپت تولید کیوآر کدهای سفارشی میزها
    ├── fonts/             # فونت‌های وزیرمتن، دانا و یکان‌بخ
    └── presets/           # ۵۶ تصویر آماده‌ی دوربُری شده، شفاف و سنتر شده با کیفیت بالا
```

## 🧩 استاندارد اتصال قالب دلخواه (Data-Attribute Contract Hooks)

برای اینکه قالب جدید شما به صورت خودکار به دیتابیس و سبد خرید متصل شود، فقط کافیست اتریبیوت‌های استاندارد زیر را به المان‌های HTML خود اختصاص دهید. تابع `renderMenu` در `assets/app.js` این المان‌ها را شناسایی و مقداردهی می‌کند.

### ۱. اطلاعات عمومی فروشگاه
| اتربیوت | توضیح عملکرد |
| :--- | :--- |
| `[data-shop-name]` | نام فروشگاه/کافه (تنظیم شده در پنل مدیریت) |
| `[data-tagline]` | شعار یا زیرعنوان مجموعه |
| `[data-footer-note]` | متن هشدار/توضیحات در پاورقی |
| `[data-today-date]` | درج خودکار تاریخ روز به زبان فارسی |
| `[data-table-badge]` | نمایش شماره میز (در صورت باز شدن با `?table=X`) |

### ۲. دسته‌بندی‌ها و ناوبری (Categories & Nav)
| اتربیوت | توضیح عملکرد |
| :--- | :--- |
| `[data-category-nav]` | کانتینر منوی ناوبری اسکرول افقی تب‌ها/پیل‌ها |
| `[data-category-list]` | کانتینر اصلی صفحه که بخش‌های دسته‌بندی در آن تزریق می‌شوند |
| `[data-category-section]` | سکشن اصلی هر دسته‌بندی (شامل شناسه `data-category-id`) |
| `[data-category-title]` | عنوان دسته‌بندی |
| `[data-category-icon]` | تگ `<img>` آیکون دسته‌بندی |
| `.photo-circle-frame` | فریم دایره‌ای آیکون اصلی که هنگام کلیک روی آیتم‌ها **چرخش ۳۶۰ درجه** می‌زند |

### ۳. کارت‌های محصول (Item Cards)
| اتربیوت | توضیح عملکرد |
| :--- | :--- |
| `[data-item-list]` | لیست نگه‌دارنده‌ی محصولات درون سکشن دسته‌بندی |
| `[data-item-card]` | کارت اصلی آیتم (دارای ویژگی‌های `data-item-name`، `data-item-price` و ...) |
| `[data-item-title]` | تگ نام محصول |
| `[data-item-desc]` | تگ توضیحات/ترکیبات محصول |
| `[data-item-price]` | تگ قیمت (یا برچسب «تماس / استعلام» در صورت بدون قیمت بودن) |
| `[data-item-img]` | تگ عکس محصول (متصل به عکس آپلودی یا پریست‌های آماده) |
| `[data-item-badge]` | برچسب وضعیت محصول (مثلاً برچسب «تمام شد» در صورت `sold_out`) |
| `[data-cart-btn]` | دکمه افزودن به سبد خرید (در حالت فقط کاتالوگ مخفی می‌شود) |

### ۴. سبد خرید و مدال تسویه حساب (Cart & Checkout Modal)
| اتربیوت | توضیح عملکرد |
| :--- | :--- |
| `[data-cart-bar]` | نوار شناور سبد خرید پایین صفحه |
| `[data-cart-count]` | شمارنده تعداد کل اقلام در سبد خرید |
| `[data-cart-total]` | مبلغ کل سبد خرید به تومان |
| `[data-cart-checkout]` | دکمه باز کردن پنجره مدال ثبت سفارش |
| `[data-cart-modal]` | پنجره پاپ‌آپ مدال ثبت سفارش |
| `[data-modal-close]` | دکمه‌ها و پس‌زمینه برای بستن مدال |
| `[data-table-input]` | فیلد انتخاب یا ورود شماره میز |
| `[data-table-locked-badge]` | برچسب قفل شدن شماره میز بر اساس کیوآر |
| `[data-order-items-list]` | کانتینر نمایش لیست اقلام انتخابی با دکمه‌های `+` و `-` |
| `[data-order-final-price]` | مبلغ نهایی پرداختی سفارش |
| `[data-order-note]` | فیلد متن ترجیحات و توضیحات مشتری |
| `[data-order-submit]` | دکمه تایید نهایی و ارسال سفارش به تلگرام و پنل |
| `[data-toast]` | کادر پیام اعلان بالای صفحه (Toast Notification) |

## ⚡ قابلیت‌های کلیدی مهندسی‌شده

### ۱. تشخیص و قفل هوشمند شماره میز (`?table=X`)
مشتری با اسکن کیوآر کد اختصاصی میز خود (مثلاً `https://site.ir/?table=5`) وارد منو می‌شود:
1. موتور جاوااسکریپت پارامتر `table=5` را از URL دریافت می‌کند.
2. شماره میز در هدر منو و نوار سبد خرید نمایش داده می‌شود.
3. در مدال ثبت سفارش، فیلد شماره میز به صورت خودکار پر شده و **قفل (`disabled`)** می‌شود تا مشتری نتواند اشتباهاً سفارش را به میز دیگری اختصاص دهد.

### ۲. انیمیشن چرخش آیکون دسته‌بندی (Pop-Spin Interaction)
هنگامی که مشتری روی هر آیتم کلیک می‌کند:
- تابع `swapCategoryIcon(section, itemImg)` آیکون دسته‌بندی را با زاویه ۳۶۰ درجه می‌چرخاند و در زاویه ۱۸۰ درجه عکس دسته‌بندی را با تصویر آیتم انتخابی جایگزین می‌کند.
- با بسته شدن کشوی آکاردئون، تابع `revertCategoryIcon` با چرخش معکوس، تصویر پیش‌فرض دسته‌بندی را بازمی‌گرداند.

### ۳. حالت «فقط کاتالوگ» (Catalog-Only Mode)
اگر رستوران یا کافه تمایلی به ثبت سفارش آنلاین نداشته باشد:
- از داخل پنل مدیریت > تنظیمات، گزینه «امکان ثبت سفارش فعال باشد» را غیرفعال کنید.
- سیستم به صورت خودکار نوار شناور سبد خرید و دکمه‌های «+ افزودن» را در کل منو مخفی می‌کند و منو به یک کاتالوگ لوکس تصویری تبدیل می‌شود.

### ۴. آیتم‌های بدون قیمت / استعلامی
- در صورتی که برای محصولی قیمت تعریف نشود (`null` یا خالی)، برچسب شکیل «تماس / استعلام» به جای عدد قیمت نمایش می‌یابد و از بروز خطاهای محاسباتی یا نمایش `۰ تومان` جلوگیری می‌شود.

## 🤖 آموزش اتصال و تنظیمات ربات تلگرام

برای فعال‌سازی اعلان‌های لحظه‌ای سفارشات و منوی استعلام ربات:

۱. وارد ربات رسمی تلگرام به آیدی `BotFather@` شوید.
۲. دستور `/newbot` را ارسال کنید و نام و آیدی ربات خود را تعیین نمایید.
۳. توکن دریافت شده (فرمت: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`) را کپی کنید.
۴. برای دریافت Chat ID اکانت مدیریت خود، پیام دلخواهی به ربات `userinfobot@` ارسال کنید و عدد `Id` را بردارید.
۵. در پنل مدیریت (`admin.html`)، وارد تب **«تنظیمات»** شوید:
   - توکن ربات تلگرام را در فیلد مربوطه قرار دهید.
   - چت آیدی را وارد کنید.
   - آدرس دامنه وب‌سایت (مثلاً `https://your-domain.ir/webhook.php`) را در بخش وب‌هوک وارد کرده و روی دکمه ثبت وب‌هوک کلیک نمایید.
۶. حال با ثبت هر سفارش توسط مشتری، مشخصات سفارش به همراه جزییات میز به تلگرام باریستا ارسال می‌شود.
۷. مدیران با زدن دکمه‌ی **«🏆 آیتم‌های پرفروش»** در تلگرام، می‌توانند گزارش فروش روز، هفته و ماه را با نمودار و درصد مشاهده کنند.

## 🚀 ملزومات اجرا و سرور
- **PHP:** نسخه 7.4 یا 8.0 و بالاتر (تست شده روی PHP 8.1 / 8.2 / 8.3).
- **ماژول‌های مورد نیاز PHP:** ماژول‌های `pdo_sqlite` یا `sqlite3`، `curl`، `openssl` و `mbstring` (در ۹۹٪ هاست‌های اشتراکی سی‌پنل و دایرکت‌ادمین فعال هستند).
- **مجوز فایل‌ها (Permissions):** فایل `menu.sqlite` و پوشه `uploads/` باید مجوز دسترسی نوشتن (`chmod 775` یا `777`) داشته باشند.
- **سازگاری با گارد راست‌چین:** تمامی فایل‌های PHP این پکیج مطابق با الزامات سورس گارد راست‌چین (تگ‌های کامل `<?php>`، مسیرهای قطعی `__DIR__` و بدون متدهای ممنوعه) بازنویسی شده‌اند.
