# کافینکس (Cafinex) — منوی آنلاین و تعاملی کافه و رستوران (PWA + ربات تلگرام)

## ۱. معرفی محصول کافینکس (Cafinex)

**کافینکس** یک اسکریپت وب‌اپلیکیشن فوق‌پیشرفته، سبک، فوق‌العاده سریع و کاملاً فارسی برای منوی دیجیتال کافه‌ها، رستوران‌ها و آبمیوه‌فروشی‌ها است. این محصول با هدف **نصب فوق‌سریع بدون نیاز به سرورهای پیچیده، بدون کامپوزر (Composer)، بدون نیاز به دیتابیس MySQL و بدون مراحل ساخت (Build Step)** توسعه یافته است.

### امکانات برجسته:
- **نصب و راه‌اندازی با ۱ کلیک:** فقط فایل‌ها را روی هاست آپلود و اکسترکت کنید.
- **فناوری PWA (Progressive Web App):** قابلیت نصب روی صفحه اصلی موبایل اندروید و iOS بدون نیاز به کافه‌بازار یا اپ‌استور.
- **کارکرد ۱۰۰٪ آفلاین:** به لطف سرویس‌ورکر اختصاصی و فونت‌ها و استایل‌های محلی، پس از اولین بازدید بدون اینترنت نیز باز می‌شود.
- **پنل مدیریت اختصاصی و واکنش‌گرا:** ویرایش دسته‌ها، آیتم‌ها، تصاویر، قیمت‌ها و تم‌های رنگی به صورت زنده.
- **سیستم مدیریت سفارشات آنلاین:** ثبت سفارش از روی میز با قابلیت انتخاب شماره میز، تعیین سفارش بیرون‌بر و درج یادداشت مشتری.
- **اتصال پیشرفته به ربات تلگرام:** اعلان لحظه‌ای سفارشات جدید با جزئیات کامل روی گوشی باریستا و قابلیت تغییر وضعیت سفارش به صورت دوطرفه از تلگرام.
- **ژنراتور کدهای QR میزها:** امکان تولید و چاپ گروهی بارکدهای QR برای میزهای کافه به صورت تفکیک‌شده.
- **حالت کاتالوگ (نمایشگاهی):** امکان غیرفعال‌سازی موقت ثبت سفارش و تبدیل منو به کاتالوگ نمایش محصولات.

## ۲. پیش‌نیازهای سرور و هاست (System Requirements)

اسکریپت کافینکس روی ۹۹٪ هاست‌های اشتراکی استاندارد بدون هیچ پیکربندی خاصی اجرا می‌شود:

| نیازمندی | حداقل نسخه / وضعیت | توضیحات |
| :--- | :--- | :--- |
| **نسخه PHP** | PHP 7.4 تا 8.2+ | کاملاً تست‌شده با خطایابی Strict Type |
| **اکستنشن SQLite3** | `pdo_sqlite` / `sqlite3` | به صورت پیش‌فرض روی تمامی هاست‌های cPanel و DirectAdmin فعال است |
| **اکستنشن cURL** | فعال (Enabled) | جهت ارتباط با وب‌سرویس تلگرام |
| **اکستنشن OpenSSL** | فعال (Enabled) | جهت رمزنگاری و ارتباط امن HTTPS |
| **انکودینگ پیش‌فرض** | `UTF-8` (بدون BOM) | پشتیبانی بی‌نقص از کاراکترهای زبان فارسی |
| **وب‌سرور** | LiteSpeed, Apache, Nginx | پشتیبانی از فایل `.htaccess` برای امنیت دیتابیس |

## ۳. راهنمای نصب سریع در ۴ مرحله (Quick Setup)

### مرحله ۱: استخراج فایل زیپ روی هاست
فایل بسته نصبی را در پوشه اصلی وب‌سایت خود (معمولاً `public_html` یا یک ساب‌دامین مانند `menu.site.com`) آپلود کرده و از حالت فشرده (Extract) خارج نمایید.

### مرحله ۲: بررسی دسترسی‌های فایل دیتابیس و آپلود
مطمئن شوید فایل‌ها دسترسی نوشتن دارند:
- فایل `menu.sqlite` و پوشه ریشه: مجوز `664` یا `666` (جهت ثبت اطلاعات توسط وب‌سرور)
- پوشه `uploads/`: مجوز `755` یا `775` (جهت ذخیره تصاویر آپلودشده محصولات)

### مرحله ۳: شخصی‌سازی فایل `config.php` (اختیاری)
فایل `config.php` در ریشه اسکریپت قرار دارد. در صورت تمایل می‌توانید رمز عبور ورود را تغییر دهید:
```php
// رمز عبور پیش‌فرض پنل مدیریت: admin123
define('ADMIN_PASSWORD', 'admin123');
define('ADMIN_KEY', ADMIN_PASSWORD);
```

### مرحله ۴: ورود به منو و پنل مدیریت
- منوی مشتریان در آدرس دامنه شما باز خواهد شد: `https://yourdomain.com/index.html`
- برای دسترسی به پنل مدیریت به آدرس زیر مراجعه نمایید: `https://yourdomain.com/admin.html`
- با وارد کردن رمز عبور **`admin123`** وارد پنل مدیریت شوید.

## ۵. راهنمای اتصال سرویس اعلان‌ها (ربات تلگرام و پیام‌رسان بله)

کافینکس دارای سیستم نوتیفیکیشن دوگانه است تا خریداران روی هاست‌های خارج یا هاست‌های داخل ایران بدون هیچ دغدغه‌ای اعلان سفارشات را دریافت نمایند:

### روش اول: پیام‌رسان ایرانی بله (ویژه هاست‌های داخل ایران — ۱۰۰٪ بدون فیلترشکن)
پیام‌رسان بله ساختار API کاملاً مشابه تلگرام دارد و به دلیل قرارگیری سرورها در شبکه ملی اطلاعات، روی کلیه هاست‌های ایرانی (آسیاتک، پارس‌آنلاین، شاتل و...) بدون نیاز به پروکسی به سرعت برق پیام ارسال می‌کند:
۱. **ساخت ربات در بله:** در اپلیکیشن بله، وارد بازوی رسمی `BotFather@` شوید و دستور `/newbot` را بفرستید.
۲. **دریافت توکن:** نام نمایشی و شناسه کاربری ربات خود را انتخاب و رشته توکن (Token) را دریافت کنید.
۳. **دریافت شناسه عددی (Chat ID) در بله:** برای برداشت چت‌آیدی، در پیام‌رسان بله به بازوی رسمی **`Show Chat ID`** مراجعه کنید تا شناسه عددی اکانت شما را نمایش دهد.
۴. **شروع ربات:** در پیام‌رسان بله وارد ربات اختصاصی خود شده و دکمه «شروع» یا دستور `/start` را ارسال نمایید تا ربات مجاز به ارسال پیام و نوتیفیکیشن به شما گردد.
۵. **تنظیم در پنل مدیریت:** در پنل ادمین (`admin.html`)، بخش **«ربات و نوتیفیکیشن‌ها»**، سرویس را روی **«پیام‌رسان بله»** بگذارید؛ توکن و شناسه چت را درج نموده و روی «ارسال پیام تستی» و سپس «فعال‌سازی وب‌هوک» کلیک کنید.

### روش دوم: ربات تلگرام (Telegram Bot — بین‌المللی)
۱. در تلگرام وارد آیدی `BotFather@` شوید و دستور `/newbot` را ارسال کنید.
۲. رشته توکن محرمانه (API Token) را کپی کنید.
۳. در تلگرام به آیدی `userinfobot@` پیام دهید تا شناسه عددی چت شما را نمایش دهد.
۴. در پنل ادمین، سرویس را روی **«ربات تلگرام»** قرار داده و توکن و Chat ID را ذخیره فرمایید.
۵. دکمه «ارسال پیام تستی» و «فعال‌سازی وب‌هوک» را بزنید.

> 💡 **نکته مهم هاست ایران:** در صورت استفاده از تلگرام روی هاست‌های داخلی، فیلد پروکسی (مانند `socks5://127.0.0.1:10808` یا `http://127.0.0.1:10809`) را تنظیم نمایید؛ یا به سادگی از «پیام‌رسان بله» استفاده کنید که نیازمند هیچ پروکسی نیست.

## ۶. اعتبارسنجی امنیتی API و ارسال توکن

تمام اندپوینت‌های اصلاحی داخل پوشه `api/` و فایل `api.php` بر اساس استاندارد هدرهای HTTP محافظت شده‌اند:
- **هدر استاندارد:** `Authorization: Bearer <ADMIN_PASSWORD>`
- **هدر جایگزین:** `X-Admin-Token: <ADMIN_PASSWORD>` یا `X-API-Key: <ADMIN_PASSWORD>`

در صورت عدم ارسال توکن یا نامعتبر بودن آن، پاسخ خطای ۴۰۱ با فرمت استاندارد UTF-8 JSON برگردانده می‌شود:
```json
{
  "ok": false,
  "error": "خطای احراز هویت: توکن یا رمز عبور مدیر نامعتبر است (Unauthorized: Invalid or missing admin token).",
  "hint": "رمز عبور پیش‌فرض admin123 است که در فایل config.php تعیین شده است."
}
```
